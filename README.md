# Understanding Git & GitHub

Learning and understanding the fundamentals of **Git and GitHub** through tutorials and hands-on practice. The focus is on learning how version control works, understanding essential Git commands, managing repositories, creating branches, committing and tracking changes, merging branches, and resolving conflicts. Also learning how GitHub is used to host repositories, collaborate with others, manage projects, and maintain a proper development workflow.

The goal is to move beyond simply memorizing commands and develop a practical understanding of how Git and GitHub are used in real-world software development.
